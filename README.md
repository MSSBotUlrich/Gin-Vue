# Gin-Vue
Projek Full Stack Latihan menggunakan Gol-ang sebagai Back End, Vue.Js sebagai Front End, dan Docker sebagai Composer

Untuk menjalankan File ini, pastikan sudah punya Docker versi Desktop untuk menjalankannya, setelah selesai Setup dan lain-lain dari Dockernya buka terminal di VsCode.

di file utamanya, ketik:
docker-compose up --build
